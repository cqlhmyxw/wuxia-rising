# 江湖山庄 · 玩法与减负设计（PLAY v1.0）

> 庄主：cqlhmyxw ｜ 2026-11-03 ｜ 状态：待审阅
> 配套：`docs/GDD.md`（世界）、`docs/SYSTEMS.md`（四体系）。本文解决一件事：**体系变大以后，人不能变累。**

---

## 0. 核心命题：认知税

体系越多，玩家要背的规则越多。这是所有"玩法丰富"的游戏最终死掉的地方——不是不好玩，是**太费脑子，下班的人没这个预算**。

常见错误解法是"做新手引导"（教一遍，然后照样累）。正确解法只有一个：

> **减少操作，不减少选择。**

- 减少**操作**：重复劳动交给代理
- 不减少**选择**：做什么、做成什么样，仍然是玩家决定

如果连选择都交出去，游戏就变成看 PPT，玩家不会再回来。这条线必须守住。

## 1. 庄务：玩家与体系之间的唯一入口

### 1.1 定位

`庄务` 不是菜单，是一个**角色**（老仆 / 山长）。它替玩家操心，玩家只做决定。

```
玩家 ──说一句话──▶ 庄务 ──▶ 修炼 / 种田 / 制作 / 交互
```

玩家**不需要**记住四个体系的规则。他只需要知道：有事问庄务。

### 1.2 三层，按"你不问就不打扰"排序

| 层 | 触发 | 形态 | 例子 |
|----|------|------|------|
| **① 提示** | 自动，每日一次 | 案上一张纸条 | 「今日谷雨，微雨。药圃该下当归了。」 |
| **② 建议** | 玩家问"现在做什么好" | 3 条，每条带**理由** | 「此刻雨停，心境可升到定，适合把那件搁了三天的剑穗做完」 |
| **③ 代办** | 玩家说"你看着办" | 木人 / 仆役执行 | 「这块地轮作，收完自动补种」 |

**三条硬规则**：
1. 提示**不带红点、不带弹窗、不带音效**。它就是一张纸条，不看也不会漏掉什么。
2. 建议必须**给理由**。给理由不是为了炫技，是为了让玩家慢慢学会规律——学会之后就不需要建议了。
3. 代办必须**可撤回**。任何时候能说"停，我自己来"。

### 1.3 「今日」卡片（第一屏，唯一的第一屏）

```
┌─────────────────────────────┐
│  谷雨 · 微雨       心境：静   │
│                             │
│  ① 药圃东畦下当归      3 分钟 │
│  ② 亭中听雨          不限时 │
│  ③ 那件剑穗可以动手了  8 分钟 │
│                             │
│  今日无事，也可只是坐坐。      │
└─────────────────────────────┘
```

- 一天只有这一张，不叠加、不轮播
- 三条都**可以不做**，明天会换新的（不会累积成待办）
- 最后那句是产品态度，也是给玩家的许可

## 2. 代办梯度：按境界解锁（回应"筑基期木人"）

| 级 | 境界 | 名称 | 能力 |
|----|------|------|------|
| L0 | 炼气 | 提醒 | 告诉你该做什么 |
| L1 | 筑基 | 代劳 | 木人执行**单一动作**：收一畦、挑一趟水、磨一袋粉；做完即停 |
| L2 | 金丹 | 方针 | 定一条**长期规矩**：这块地轮作、收完自动补种、成熟即入仓 |
| L3 | 元婴 | 协作 | 多个木人**串联成线**：种 → 磨 → 送作坊 |
| L4 | 化神 | 自主 | 整座山庄按玩家设定的"性子"运转 |

### 2.1 四条约束（自动化的刹车）

| 约束 | 机制 | 为什么 |
|------|------|--------|
| **木人吃灵气** | 每个木人按日消耗灵气，灵气由打坐与气象产出 | 不修炼 → 木人停摆。修炼仍是根，自动化不能替代成长 |
| **木人手笨** | 木人产出品质上限比手作低 1~2 档 | 想做精品必须亲手。手作永远有价值 |
| **木人不会悟** | 木人干活不涨熟练度 | 熟练度只能亲手练。想解锁新配方，必须自己动手 |
| **只做你会的** | 只接玩家**亲手完成过 3 次以上**的活 | 必须先学会，才能交出去。学习曲线不被跳过 |

**一句话**：把重复交出去，把"学会"和"做好"留给自己。

### 2.2 UI 上怎么呈现

- 木人不是一个"功能按钮"，是**站在田里的一个东西**。走过去能看到它在干活，能叫停，能换方针
- 木人身上挂一块木牌，写着当前方针（玩家自己起的名字，如"东畦·轮作"）
- 不显示效率百分比，不显示"今日产出 12 单位"。**不做数值仪表盘**——那是给上班的人再上一份班

## 3. 评估：事前预览 + 事后复盘

### 3.1 事前预览（做之前告诉你可能的结果）

制作 / 种植 / 渡气时，面板直接给出预估：

```
这件剑穗
  心境  静    +15% 品质
  材料  二等  -1 档
  熟练  初识  基础 0.4
  ───────────────────
  预估  粗制 ~ 中品

  建议：再等一场雨，心境可到「定」，有望出上品。
```

**关键**：给出的是**预测**，不是**结论**。玩家仍可以现在就做（急用），只是知道代价。

### 3.2 事后复盘（可选，从不强制）

做完一件东西，可以点"看看"（不给红点）：

- 三因子拆解：这次差在哪（心境？材料？熟练？）
- 记入"手记"：「第三十七日，第一次做出上品。那天下雨。」

**不做**：评分、星级、排名、"超过 78% 的玩家"。

### 3.3 素心模式（一键关掉所有辅助）

想自己摸索的玩家，可以关掉全部提示、建议、预览、复盘，进入素心模式：

- 无提示、无建议、无预估
- 野兽不主动攻击
- 界面上只剩景物与四个基本操作

**这是给"不想被系统管"的人的出口，也是本作对"沉浸"的最终诚意。**

## 4. 减法六则（硬约束，违反即设计失败）

| # | 规则 | 具体做法 |
|---|------|---------|
| 1 | **一次只呈现一件事** | 主界面永远只有一张今日卡片，不做面板堆叠 |
| 2 | **默认最优** | 每个选择都有默认值，可以一路「就这样」 |
| 3 | **渐进披露** | 新系统只在第一次需要时出现，首次出现只有一个按钮 |
| 4 | **参谋制** | 复杂决策只给「推荐 + 一句理由」，玩家允 / 否 |
| 5 | **不做并列选择** | 不给六个选项让玩家比较，给一个推荐 + 「换一个」 |
| 6 | **可托管** | 第二次做同一件事时主动问「以后都这样办？」，点了就自动化 |

**验收方法**：让一个没看过设计文档的人玩 10 分钟，不给他任何说明。如果他问出"我现在该干嘛"，减法就失败了。

## 5. 闲事（历练系统）

### 5.1 定位

**不给战力，给"见闻"与"心境"。**

为什么这样定：一旦历练给战力，它就会变成第五条日常任务线，玩家的负担不减反增。而"见闻"的作用是让世界变厚——解锁手记条目、对话选项、对节气与药材的认知。它不参与数值竞争。

### 5.2 八件闲事

| 玩法 | 怎么玩 | 产出 | 缺席会怎样 |
|------|--------|------|-----------|
| **垂钓** | 池边/溪边抛竿，可走开，回来收 | 鱼（放生涨心境 / 养缸 / 做菜）、心境缓升 | 鱼不跑，竿还在 |
| **采药** | 后山按节气刷新，靠「识药」发现稀有 | 药材、见闻 | 药材会过季，但下季还有 |
| **种花** | 纯观赏，影响「景」评分 | 可剪枝赠人（借景素材） | 花不枯，只是开过了 |
| **观星** | 夜上观云台 | 天时知识（预测节气与天气） | — |
| **弈棋** | 与 NPC 下残局，或与远方之人异步对弈 | 心境、熟识 | 一步可以等三天 |
| **抚琴** | 简单旋律复现，弹错也不惩罚 | 心境、生成一段「曲」可赠 | — |
| **品茶** | 用自种的茶泡一壶 | 心境、可待客 | 茶叶会陈，但不坏 |
| **山行** | 后山小径漫游，遇野兽、遇奇景 | 见闻、山货 | — |

### 5.3 「气机相争」（轻战斗）

不做血条对砍。山中的野猪、独狼会挡路，用三段博弈解决：

```
每段选一：进 / 守 / 引
相克：进克引，引克守，守克进
三局两胜，先乱者败
```

| 结果 | 后果 |
|------|------|
| 胜 | 野兽退走，山林产出恢复，得山货 |
| 负 | **气机溃散**：元气 -10%，被送回庄门。不死亡、不掉物、不读档 |

**四种应对**：正面相争 / 绕路 / 设陷阱 / 点驱兽香。素心模式下野兽不主动攻击。

**设计意图**：武侠的"交手"本应是气势之争，不是互相砍血条。这样既满足了"偶尔想动手"，又不会长成一条战斗线。

## 6. 社交：六件具体的事

> 原则承接 SYSTEMS：只做异步，不实时、不打扰。下面是把框架落成可玩内容。

| 玩法 | 形态 | 技术 | 为什么适合忙人 |
|------|------|------|---------------|
| **弈棋** | 异步对弈，一人一步，一盘可三天 | 棋盘状态存 inbox | 有来有回却不同时在线 |
| **书信** | 长信，可附种子/图样/诗/字 | 消息队列，延迟 1~3 天投递 | 不是聊天，是说完整一段话，压力低 |
| **尝新宴** | 自种菜办一场，请 NPC 与远方之人；来客留一句评语 | 事件广播 + 留言 | 一年一次也不亏，办一次记很久 |
| **托付** | 把山庄交给某人照看几天，回来读他的《庄务记》 | 授权标记 + 代理行为记录 | 信任的最高形式，「被惦记」的最强形态 |
| **师徒** | 高阶收徒，教功法、给图样；出徒得名望 | 单向关系链 | 老玩家有事做，新玩家有人带 |
| **邻里守望** | 地图上的邻居，可借道、换种、帮灭火（随机事件） | 空间邻接 + 事件 | 不必说话，但知道旁边有人住 |

**仍然不做**：实时聊天、私信、语音、点赞、热度、关注数、好友列表（用「熟识」与「书信」代替）。

### 6.1 为什么不做好友列表

好友列表会制造"该维护关系"的压力，而且一旦人数为 0 就显得冷清。用「邻居」和「熟识」替代：关系由**共同经历**累积，不由加好友产生。

## 7. 重新计算时间预算

| 频率 | 时长 | 内容 |
|------|------|------|
| **每天** | 3~5 分钟 | 看今日卡片、收一茬、打坐一次。**可以只做一件** |
| **每周** | 20~30 分钟 | 做一件精品、下几步棋、回一封信 |
| **每月** | 1~2 小时 | 突破境界、改造山庄一角、办一次宴 |
| **想彻底放松时** | 不限 | 钓鱼、观星、山行、听雨——不产出也不亏 |

**新增约束**：任何一次登录，**必须能在 60 秒内完成一件事并退出**。这是给"只有一分钟"的人留的门。

## 8. 里程碑调整

原 M4/M5/M6 不变，新增横切能力与两条支线：

| 里程碑 | 内容 | 验收 |
|--------|------|------|
| **M4 修炼与制作** | 五法修炼、心境状态机、制作+预览+署名 | ① 雨天亭中能升「定」② 做前能看到预估 ③ 静下来做的明显更好 |
| **M4.5 庄务** | 今日卡片、三条建议（带理由）、事后复盘 | ① 第一屏只有一张卡片 ② 建议都带理由 ③ 复盘可关 |
| **M5 种田与木人** | 三块地、土壤、节气、灵植、**L1~L2 木人** | ① 筑基能召唤木人收一畦 ② 金丹能定方针 ③ 木人吃灵气，灵气断了会停 |
| **M6 交互与人** | NPC 并行共处、题壁、赠礼、客访、**弈棋与书信** | ① 不说话也能陪坐 ② 三天后收到回信 ③ 能收到来访记 |
| **M7 闲事** | 垂钓、采药、种花、观星、气机相争、素心模式 | ① 钓鱼可走开 ② 素心模式能全关辅助 ③ 输了不掉物 |
| **M8 打磨分发** | 音、PWA、移动端、分享 | 同原 |

**排序建议**：M4 → **M4.5 庄务** → M5 → M6 → M7。

**庄务必须早做**。它不是锦上添花的功能，它是**整套复杂度的出口**。没有它，前四个体系一上线，玩家第一次登录就会被劝退。

## 10. 不做什么

- ❌ 新手引导弹窗、强制教程
- ❌ 每日任务、签到、体力、限时活动
- ❌ 效率仪表盘（"今日产出 12 单位"这类）
- ❌ 自动战斗、扫荡、一键完成全部
- ❌ 好友列表、私信、点赞、热度
- ❌ 数值评分与"超过 78% 的玩家"
