# 江湖山庄 · 建造与开发（BUILD v1.0）

> 庄主：cqlhmyxw ｜ 2026-11-03 ｜ 状态：待审阅
> 配套：`GROWTH.md`（神通与木人）、`SYSTEMS.md`（四体系）、`PLAY.md`（庄务）。
> 本文回答一个核心命题：**山庄最大的成就感来自"把荒山变成自己的作品"——建设必须是主玩法，不是装修。**

---

## 0. 设计根：建设 = 可见的、永久的、自己的

三条铁律：

1. **可见**——你开出的每一级梯田、挖通的每一段水渠，都在地形上永久存在，别人来你家一眼看到你的工程。
2. **永久**——建设成果只增不减（可改造、可拆除重建，但不会朽坏回退），是和"气象"并列的第二条只涨不跌的成长线。
3. **自己的**——每一级梯田记录"谁开的、什么节气、用了什么法子"。山就是你修为和手艺的实物档案。

**成就感公式：`荒山 → 梯田层层 → 渠水自流 → 木人耕作 → 站在观云台俯瞰，全是你干的。`**

## 1. 开山线：从一座荒山到千级梯田

### 1.1 山体分带（空间即进度条）

后山不是一整块背景板，是**可逐段开发的工作面**，从下往上五带：

| 带 | 初始状态 | 开发后 | 主要产出 |
|----|---------|--------|---------|
| 山麓带（0~15m 高差） | 灌木乱石 | **梯田一层**（开园即有 2 畦薄田） | 五谷、桑麻 |
| 山腰带（15~40m） | 密林 + 一处裸露矿脉 | **梯田二三层 + 竹林驯化** | 灵稻、茶、竹 |
| 山脊带（40~70m） | 陡峭，无法耕作 | 需"垒石固土"（石工）才能开梯 | 高山灵药 |
| 观云台（山顶） | 一块平石 | 神通与风景节点（不可耕） | 观星、御物起跳点 |
| 山腹（矿洞） | 封闭 | 挖掘线（见 §2） | 矿石 |

**梯田是"造出来的地"**：游戏开局只有山麓 2 畦薄田。想要更多，就得自己开——这就是种田快乐的第一来源：*地是挣出来的，不是系统给的*。

### 1.2 开垦工序（渐进，不一步到位）

开一段荒坡 → 成一畦好田，分四步，每步可交给木人但**首次必须亲手**：

1. **斫木**（斧/锯，木工系）——清理灌木，得木料
2. **除石**（镐，石工系）——碎石垒到田埂上，得石料（边开田边产建材，无废料）
3. **翻土**（锄，农事系）——生土翻成熟土，决定首季肥力
4. **引水**（水利）——接渠或挖塘，决定这一带能种什么（见 1.3）

**每一步的手感差异是玩法**：翻土的熟土度、垒埂的走向影响水土保持——亲手开的地有"手作痕迹"，木人开的地整齐但千篇一律（呼应"神通省力，功夫不涨"）。

### 1.3 水利：山庄的血管

水是开发上限的总开关，三种工程：

| 工程 | 解锁 | 作用 |
|------|------|------|
| **导流渠** | 石工 2 级 | 从溪口引水下山，渠过之处坡地才能开成水田 |
| **蓄水塘** | 水利工具 | 旱季供水 + 养鱼 + 倒影风景（四气里的"地气"上限 +10/塘） |
| **翻车/筒车** | 机关术 3 级 | 木质提水机，把水送上高处——**高带梯田的钥匙** |

渠网走向由你画（造化神通后期甚至能直接改地形），**水往哪流、田就活到哪**——这本身就是个益智建造玩法。

### 1.4 能力怎么用进建设（神通 × 工程）

| 神通/手艺 | 用在建设上 |
|-----------|-----------|
| 感气（炼气） | 看见土的肥气/水的灵气走向，**选梯田位置和渠线全靠它** |
| 御物（筑基） | 隔空垒石夯土，除石工序速度 ×3 |
| 造化（合体） | 直接移动一小块地形——削山填谷，终局建设自由度 |
| 机关术 × 木工 | 造木人（见 §1.5）、筒车、锯木架 |
| 木人梯队 | 见下 |

### 1.5 木人工程队（把"开发"滚起来）

与 GROWTH 的木人器物化一致，建设类木人是**专门一支**：

| 木人 | 配方 | 干什么 |
|------|------|--------|
| 担水童 | 机关 1 + 木工 2 | 挑水浇田（开局第一个木人，最亲切） |
| 开荒壮 | 机关 2 + 石工 2 | 斫木/除石/翻土一条龙，可多个组队开高带 |
| 垒埂匠 | 机关 3 + 石工 3 | 自动修渠筑埂，走向按你画好的线走 |
| 筒车工 | 机关 3 + 水利 2 | 维护翻车，雨天自动蓄水 |
| 矿工髅 | 机关 4 + 矿采 3 | 矿洞掘进与运矿（见 §2） |

**快乐节奏**：第一周亲手开完山麓 4 畦 → 做出担水童解放挑水 → 第二周开荒壮上腰带，你只管画渠线、选作物 → 每多一具木人，你的"眼光"就更值钱（规划才是你不可替代的部分）。

## 2. 取矿线：矿层、矿石与工具迭代

### 2.1 矿洞与矿层

山腹矿洞（石工 1 级敲开洞口），**越深越稀有、越危险（气机相争的野兽）、越需要照明与支撑**：

| 层 | 深度 | 产出 | 门槛 |
|----|------|------|------|
| 表层 | 洞口 | 石料、黏土、少量铁矿 | 石工 1 |
| 中层 | -20m | 铁矿、铜矿、煤 | 铁镐 + 灯 |
| 深层 | -50m | 玄铁、云母、寒玉 | 铜镐 + 探灵（感气在洞里的用法：**矿脉的灵丝肉眼可见**） |
| 心髓 | 矿洞尽头 | 天外陨铁（一洞一块） | 元婴分神（一边举灯一边凿） |

矿洞结构程序化生成，每季塌方一次重新洗牌部分通道——矿洞是**可重复探索**的。

### 2.2 工具迭代（效率的阶梯）

**"用不同矿石做不同工具，大大提升效率"**——落成一条清晰的工具树：

| 工具档 | 材料 | 效率 | 附带 |
|--------|------|------|------|
| 石器 | 石料 | ×1 | 开局 |
| 铁器 | 铁矿 + 煤 | ×2 | 中层矿解锁 |
| 玄铁器 | 玄铁 | ×3.5 | 深层矿；**可淬火（筑基神通）再 +1 品** |
| 云母器 | 玄铁 + 云母 | ×5 | 带灵性：用久了"认主"，越用越顺手 |
| 陨铁器 | 陨铁 | ×8 + 专属词条 | 一人一套，传世品质，可署名（社交货币） |

**工具是"养"出来的**：每件工具有自己的熟练度（同 GROWTH 的器物逻辑），云母镐挖了三个月，会开始"往矿脉厚的地方偏"——好工具是伙伴，不是耗材。

**反哺闭环**：好工具 → 开田/挖矿更快 → 更多材料 → 做更好工具/更多木人 → 开发更高更深的山。**这就是"举一反三"的那个自驱循环。**

### 2.3 锻造与品阶

- 矿石 ≠ 直接用：需**锻打**（锻造手艺）+ 心境系数（静下来打铁，杂质去除率高——SYSTEMS 的核心公式在建设线的应用）
- **淬火**（筑基御物的应用）：观火色（内视更佳），时机对了品阶 +1
- 失败不炸炉：只是出"凡品"，材料部分回收——鼓励敢做，不惩罚失败

## 3. 获得感的三个固化装置

让"我建成了"被看见、被记住：

1. **《山庄图志》**：一张随建设自动绘制的全庄长卷（俯视水墨图），每开一畦田、通一段渠，画卷上就多一笔。**你的存档 = 一幅越来越满的画**，随时可赠友人（异步社交素材）。
2. **碑与名**：大工程完工可立碑刻字（书法熟练度影响碑文品相），碑可被来访之人读到——建设直接接上交互线。
3. **远望体系**：化神后你的山庄轮廓会被邻庄"远望"到——**梯田层层、渠水反光的山庄，远看就是不一样的**。建设是给别人看的风景。

## 4. 节奏与减负（遵守 PLAY 减法六则）

- 开垦四步**默认一键**（庄务代办），想手作再逐步——自动最省，手作最优（熟土度更高）
- 矿洞每次进入**给一个目标建议**（"今日缺煤，中层东道三处矿脉有灵丝"），不逼你背地图
- 全部建设产出走**时间戳离线结算**，木人干活不需要你在线盯
- 一次登录 60 秒内：点一下"批准今日工程"或亲手抡一锤，都算数
