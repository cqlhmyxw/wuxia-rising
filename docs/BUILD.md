**成就感三源头（v2.0 修正）：**

## 1. 梯田主线：把一整面山开成作品

### 1.1 规模即目标

后山南坡（向阳面）是**一整面可开发的山体**，从山脚到山腰共 **40 级梯田**的容量：

| 阶段 | 累计梯田 | 视觉 |
|------|---------|------|
| 开局 | 2 畦薄田 | 山还是荒的 |
| 第一月 | 8~10 级 | 山脚一圈绿带 |
| 第一季（M5.1 完） | 20 级上下 | 半面山成阶 |
| 长线 | **40 级满开** | **站在观云台俯瞰：千层翠浪，一眼望不到边**——这是本作的第一画面 |

**梯田本身就是观景奖励**：开到 10 级起，观云台解锁"俯瞰"视角（镜头升起的长镜头，配云雾流动）——**你开出来的山，游戏用电影镜头还给你看**。满开之日，全庄异象"青浪拂云"，永久记录在《山庄图志》。

### 1.2 一级梯田的生命周期

开垦（斫木→除石→翻土→引水）→ 选种（按节气/带高）→ 耕作（可手作可木人）→ 收获 → **养地**（连作耗肥，豆类/苜蓿固氮轮作）。

- **带高决定品种**：低带水稻桑麻、中带茶竹灵稻、高带高山药——40 级不是重复劳动，是**垂直气候带**
- **田埂即道路**：梯田天然形成之字形步道，行走本身变成风景
- **水从上往下串**：最上一级接渠，水逐级下淌——**上家田的余水是下家田的活水**，级与级有了依存关系，规划错了下游旱

### 1.3 神通 × 梯田

| 神通 | 用法 |
|------|------|
| 感气（炼气） | 看土肥水脉，选每级种什么、渠怎么走 |
| 御物（筑基） | 隔空垒埂搬石，开垦 ×3 速 |
| 内视（金丹） | 看出田的"里子"——缺肥缺水一眼知 |
| 造化（合体） | 削直坡、填谷洼——**把不规整的山改成你想要的等高线**，终局自由度 |

## 2. 水系线：山庄的命脉（新增，独立成线）

水不是装饰，是**全庄产业的调度系统**：

| 元素 | 来源 | 产业作用 |
|------|------|---------|
| **溪流** | 山顶泉眼，天然生成 | 全庄水源总纲；下游落差可推水碓（自动舂米） |
| **瀑布** | 山脊断崖 | 站桩修炼点（GROWTH）；落差即动力 |
| **导流渠** | 玩家画线开凿 | 梯田供水；渠尾接塘不浪费 |
| **蓄水塘** | 挖掘 | 养鱼、鸭、灌溉缓冲、倒影风景 |
| **筒车/水碓/水磨** | 机关术 | 提水上山 / 自动舂米 / 自动磨面——**水力机关是"机械化"的第一步**，先于木人 |

**玩法**：水是稀缺资源——泉眼流量恒定，渠分得多下游就少。**一张全庄水账**（庄务可代算）：给梯田多留，鱼塘就要浅；筒车抢水，瀑布下的站桩点灵气就弱。取舍即策略。

## 3. 矿业线：另立山头（与梯田彻底分离）

**矿在对面山的"黑石谷"**——一座寸草不生、岩壁裸露的秃山，与青绿梯田形成鲜明色彩对比（一眼就懂"那边是干粗活的"）：

| 区 | 内容 |
|----|------|
| 露天矿坑 | 山体丵开的大坑，石料/黏土/煤，最直观的"工地" |
| 矿洞（四层） | 表层→中层（铁铜煤）→深层（玄铁云母寒玉）→心髓（陨铁，一洞一块） |
| 锻造坊 | 谷口建坊：炉、砧、淬火池；**烟囱日夜冒烟——工业感与山庄的田园感隔着一条溪各过各的** |
| 淘沙溪 | 黑石谷下游一段沙溪：淘金/淘云母砂，垂钓线与矿线在这里交汇 |

- 感气看矿脉灵丝；每季塌方洗牌矿洞通道
- **工具五档**不变：石→铁→玄铁→云母（认主）→陨铁（传世署名）
- 野兽（气机相争）聚在黑石谷——**危险集中在矿区，山庄本体永远安全**，两个空间两种心情

## 4. 养殖线：让山庄活起来（新增）

**原则：养的是"伙计和风景"，不是掉落数字。** 六类，从易到难：

| 类 | 内容 | 产出 | 生机表现 |
|----|------|------|---------|
| **鸡鸭** | 篱笆圈养，开局可得 | 蛋、羽 | 清晨鸡鸣、塘边鸭群——山庄每天被它们叫醒 |
| **鱼塘** | 蓄水塘放苗 | 鱼（食用/观赏/放生涨心境） | 投喂时鱼群聚拢翻花 |
| **羊群** | 需牧羊犬或牧童木人带领 | 羊毛（织布/书画毡）、羊奶 | **白天上山吃草，日暮列队归圈**——可设放牧路线 |
| **蜂箱** | 花田旁边放，蜂自己采 | 蜜（灵蜜助心境） | 花开时节蜂群绕田——**你的花田越大蜜越好，种花与养蜂联动** |
| **蚕** | 桑田配套 | 丝（绫罗，织造高端材料） | 桑叶喂蚕、结茧缫丝，完整农桑链条 |
| **鹿/鹤** | 不圈养，**半驯**：定期投喂会常来，仙鹤落点固定 | 观赏、心境、远望风景 | 神通感气可见兽群动向；鹤至=吉兆，全庄异象之一 |

**养殖的"能力绑定"**：
- 感气（炼气）：看牲畜气色，病了先知
- 御物（筑基）：隔空收蛋捡羊毛
- 木人：**牧童**（机关2+牧2，领羊上山）、**饲雏童**（机关1+牧1，喂鸡鸭收蛋）、**渔翁**（机关3+渔2，看塘）
- 分神（元婴）：一心放羊一边采药——**放牧是天然的"挂机同时干活"场景**

**羊毛→织机→布→衣袍/书画毡/买卖**——养殖接通制作线，产业开始咬合。

## 5. 林业与采集（补全）

- **竹林驯化**：山腰野竹笋移植成林，竹材供机关术（木人的本体材料），竹林随风摆=风景
- **果林嫁接**：嫁接手艺决定品种（普通桃→灵桃），一年一熟，秋天全庄摘果
- **采药**：后山按节气刷新（SYSTEMS 原案），感气可见药气
- **渔猎**：垂钓（PLAY 原案）；狩猎归入黑石谷气机相争，**山庄周边不打猎**——田园归田园

## 6. 产业全景总表（一眼看清有什么）

| 产业线 | 核心循环 | 解锁 | 反哺谁 |
|--------|---------|------|--------|
| **农（梯田）** | 开垦→轮作→收获→养地 | 开局 | 灵食助修炼、食材给烹饪 |
| **水（水系）** | 画渠→调度→水力机关 | 开局溪流，M5.1 造渠 | 全部产业的命脉 |
| **牧（养殖）** | 饲养→收产→繁育 | 炼气期可得鸡鸭 | 毛丝布料、蜂蜜心境 |
| **林（竹果药）** | 移植→驯化→采伐/采摘 | 石工1 | 竹材→机关术、果→酿酒 |
| **渔（塘/溪）** | 投苗→垂钓→放生 | 蓄水塘 | 食材、心境 |
| **矿（黑石谷）** | 掘进→选矿→锻造 | 石工1 | 全部工具迭代 |
| **坊（锻造/织造/酿造/机关）** | 材料→制作→品阶 | 随材料解锁 | 器物反哺各线 |

**七线不要求全开**——庄务按你庄里的气象和心境内推三条最值得的，其余永远等着（PLAY 减法六则：不做并列选择）。
