## 0. 设计根：获得感 = 修为变成山水

一句话：**修炼得到能力，能力改造大地，大地产生产出，产出反过来养你。** 每一步都看得见：

```
修炼（元气/神通）→ 改造（开田/引水/掘井/驯兽）→ 产业（农/林/牧/渔/矿/坊）
      ↑______________________________________________|
              产出反哺：灵食助修炼、灵材助制作、气象助境界
```

**成就感三源头：**
1. **规模**——一眼望不到边的千级梯田，是你一锄头一锄头开出来的
2. **生机**——湖里有鱼、坡上有羊、林间有蜂，山庄是活的
3. **秩序**——渠水各归其道、羊群日暮自归圈，这份井然是你规划的

## 1. 梯田主线：把一整面山开成作品

### 1.1 规模即目标

后山南坡（向阳面）是**一整面可开发的山体**，从山脚到山腰共 **40 级梯田**的容量：

| 阶段 | 累计梯田 | 视觉 |
|------|---------|------|
| 开局 | 2 畦薄田 | 山还是荒的 |
| 第一月 | 8~10 级 | 山脚一圈绿带 |
| 第一季（M5.1 完） | 20 级上下 | 半面山成阶 |
| 长线 | **40 级满开** | **站在观云台俯瞰：千层翠浪，一眼望不到边**——本作第一画面 |

**梯田本身就是观景奖励**：开到 10 级起，观云台解锁"俯瞰"镜头（镜头升起的长镜头，配云雾流动）。满开之日，全庄异象"青浪拂云"，永久记录在《山庄图志》。

### 1.2 一级梯田的生命周期

开垦（斫木→除石→翻土→引水）→ 选种（按节气/带高）→ 耕作（可手作可木人）→ 收获 → **养地**（连作耗肥，豆类/苜蓿固氮轮作）。

- **带高决定品种**：低带水稻桑麻、中带茶竹灵稻、高带高山药——40 级不是重复劳动，是**垂直气候带**
- **田埂即道路**：梯田天然形成之字形步道，行走本身变成风景
- **水从上往下串**：最上一级接渠，水逐级下淌——**上家田的余水是下家田的活水**，级与级有了依存关系，规划错了下游旱

### 1.3 神通 × 梯田

| 神通 | 用法 |
|------|------|
| 感气（炼气） | 看土肥水脉，选每级种什么、渠怎么走 |
| 御物（筑基） | 隔空垒埂搬石，开垦 ×3 速 |
| 内视（金丹） | 看出田的"里子"——缺肥缺水一眼知 |
| 造化（合体） | 削直坡、填谷洼——**把不规整的山改成你想要的等高线**，终局自由度 |

## 2. 水系线：山庄的命脉

水不是装饰，是**全庄产业的调度系统**：

| 元素 | 来源 | 产业作用 |
|------|------|---------|
| **溪流** | 山顶泉眼，天然生成 | 全庄水源总纲；下游落差可推水碓（自动舂米） |
| **瀑布** | 山脊断崖 | 站桩修炼点（GROWTH）；落差即动力 |
| **镜湖** | 山谷筑坝汇溪成**大湖** | **全庄水景主角**：主渔场（大水面多种鱼群分层）、湖心亭、泛舟游湖、鹤栖地、倒影映四季——钓鱼就钓在这里，湖大鱼多景深 |
| **导流渠** | 玩家画线开凿 | 梯田供水；渠尾接塘不浪费 |
| **蓄水塘** | 挖掘 | 田间灌溉缓冲（小而多，散布田头） |
| **筒车/水碓/水磨** | 机关术 | 提水上山 / 自动舂米 / 自动磨面——**水力机关是"机械化"的第一步**，先于木人 |

**玩法**：水是稀缺资源——泉眼流量恒定，渠分得多下游就少。**一张全庄水账**（庄务可代算）：给梯田多留，镜湖就浅；筒车抢水，瀑布下的站桩点灵气就弱。取舍即策略。

## 3. 矿业线：地底无尽矿井（不露天、不毁山）

**取消露天矿山。** 地表只留一处入口——后山绿荫下的**天然溶洞口**（或一口废弃古井），山还是那座青山。**矿在地下，越挖越深，没有底。**

### 3.1 深度即进度条（程序化无限分层）

| 层 | 深度 | 产出 | 门槛 |
|----|------|------|------|
| 表土层 | 0 ~ -20m | 石料、黏土、少量铁矿 | 石工 1 |
| 岩层 | -20 ~ -80m | 铁矿、铜矿、煤 | 铁镐 + 矿灯 |
| 灵岩层 | -80 ~ -200m | 玄铁、云母、寒玉 | 铜镐 + 探灵（感气在井下看矿脉灵丝） |
| 地脉层 | -200m 以下 | 陨铁、星髓、地心晶髓 | 元婴分神（一边举灯一边凿）+ 御水御火神通 |

- **每层程序化生成巷道网络**，玩家自己决定往哪挖：竖井求深、平硐求广
- **越深越危险**：深层洞穴生物（气机相争的对手）和地火/地水异动都在井下，**地表永远安全**
- **没有终点的钩子**：每隔 100 米地层品质上一档，"再挖深一层会是什么"永远成立

### 3.2 井下工程（机关术的用武之地）

| 工程 | 作用 |
|------|------|
| 绞盘升降机 | 机关术 2 级，载人载矿上下竖井 |
| 支撑与加固 | 木工，防塌方（塌方会封路，不会死人） |
| 通风井 | 深层必需，兼作快速返回通道 |
| 矿车轨道 | 机关术 4 级，木人矿工沿轨运矿 |
| 照明（灯笼/萤石） | 深层全黑；萤石是可采集的天然光源 |

### 3.3 取之有度（环保即道）

- 矿渣**回填旧巷**，洞口最小化，**山川不毁**——这本身就是本作的价值观：改造大地而不毁大地
- 井下"气脉"：矿挖太急会伤地脉（周边泉水减弱），**留有余地反而地气回升**——开采强度是又一个取舍维度

### 3.4 工具迭代（不变）

石 ×1 → 铁 ×2 → 玄铁 ×3.5（筑基淬火 +1 品）→ 云母 ×5（认主，用久了自动往厚矿脉偏）→ 陨铁 ×8 + 专属词条（传世署名）。工具自己有熟练度，是伙伴不是耗材。

## 4. 养殖线：让山庄活起来

**原则：养的是"伙计和风景"，不是掉落数字。** 六类，从易到难：

| 类 | 内容 | 产出 | 生机表现 |
|----|------|------|---------|
| **鸡鸭** | 篱笆圈养，开局可得 | 蛋、羽 | 清晨鸡鸣、塘边鸭群——山庄每天被它们叫醒 |
| **鱼塘/镜湖渔场** | 蓄水塘放苗，大鱼群在镜湖 | 鱼（食用/观赏/放生涨心境） | 投喂时鱼群聚拢翻花；湖心亭撒饵，湖面一圈涟漪 |
| **羊群** | 需牧羊犬或牧童木人带领 | 羊毛（织布/书画毡）、羊奶 | **白天上山吃草，日暮列队归圈**——可设放牧路线 |
| **蜂箱** | 花田旁边放，蜂自己采 | 蜜（灵蜜助心境） | 花开时节蜂群绕田——**你的花田越大蜜越好** |
| **蚕** | 桑田配套 | 丝（绫罗，织造高端材料） | 桑叶喂蚕、结茧缫丝，完整农桑链条 |
| **鹿/鹤** | 不圈养，**半驯**：定期投喂会常来 | 观赏、心境、远望风景 | 鹤栖镜湖湖心亭，**鹤至 = 吉兆**，全庄异象之一 |

**养殖的能力绑定**：感气看牲畜气色、御物隔空收蛋捡毛、牧童/饲雏童/渔翁木人代劳、分神放牧同时采药。羊毛→织机→布→衣袍——养殖接通制作线。

## 5. 林业线：从竹林到名木园

### 5.1 常规林业

- **竹林驯化**：山腰野竹笋移植成林，竹材供机关术（木人本体材料），竹林随风摆 = 风景
- **果林嫁接**：嫁接手艺决定品种（普通桃→灵桃），一年一熟，秋天全庄摘果
- **采药**：后山按节气刷新（SYSTEMS 原案），感气可见药气

### 5.2 名木园（新增：珍稀树木种植）

**珍稀树不是"种下去等收"，是"养一棵活宝"**——每种名木是一条长线养成，木材品级直接决定高端制作上限：

| 名木 | 得法 | 养法 | 材出 | 用途 |
|------|------|------|------|------|
| 金丝楠 | 深山寻苗（感气可见树气） | 培土三季、方能移栽 | 金丝楠木 | 高级家具、琴体——**百年成材**，是山庄的传家树 |
| 银杏 | 邻庄交换/书信赠苗 | 耐心浇灌，秋天满树金 | 银杏果、木 | 果入药，秋景一绝（四季系统的明星） |
| 沉香木 | 名木园偶遇 | 伤口结香（**要故意划伤树干**——养树的悖论趣味） | 沉香 | 香料：静室焚香 = 心境辅助 |
| 竹中之灵·紫竹 | 竹林里万里挑一 | 移栽后需灵泉浇灌 | 紫竹 | 箫笛、高级机关骨架 |
| 菩提 | 只能由**点化**而生（GROWTH 神通） | 以本命气温养 | 无材可用，只有"境" | 树下打坐心境上限 +1，落叶可写字 |
| 扶桑/建木（传说级） | 地脉层深处拾得种子 | 造化神通改造地脉方能栽活 | —— | 终局内容：一棵通天的树，山庄图志的封面 |

- **名木园选址**要感气看树气——栽对了灵气肉眼可见地变旺
- 名木**可被借景**（SYSTEMS 交互）：你的百年金丝楠可以去别人庄里待七天
- 名木成长以**年**计，但每一季都有可见变化（抽芽/拔高/变色）——**长线情感投资，图志每年给你画一笔**

## 7. 产业全景总表（一眼看清有什么）

| 产业线 | 核心循环 | 解锁 | 反哺谁 |
|--------|---------|------|--------|
| **农（梯田）** | 开垦→轮作→收获→养地 | 开局 | 灵食助修炼、食材给烹饪 |
| **水（溪湖渠塘）** | 画渠→调度→水力机关 | 开局溪流 | 全部产业的命脉 |
| **牧（养殖）** | 饲养→收产→繁育 | 炼气期可得鸡鸭 | 毛丝布料、蜂蜜心境 |
| **林（竹果药 + 名木园）** | 移植→驯化→养成 | 石工1 / 感气寻苗 | 竹材→机关术、名木→高端制作 |
| **渔（镜湖/塘）** | 投苗→垂钓→放生 | 蓄水塘 | 食材、心境 |
| **矿（无尽矿井）** | 掘进→选矿→锻造 | 石工1 | 全部工具迭代 |
| **坊（锻造/织造/酿造/窑/纸/机关）** | 材料→制作→品阶 | 随材料解锁 | 器物反哺各线 |

**七线不要求全开**——庄务按气象和心境内推三条最值得的，其余永远等着（PLAY 减法六则）。

## 8. 获得感的固化装置

1. **《山庄图志》长卷**：随建设自动增笔——梯田、湖、羊群、名木、烟囱都会画进去。**存档 = 一幅越来越满、越来越活的画**
2. **观景镜头**：梯田 10 级解锁俯瞰、镜湖成湖解锁泛舟视角、鹤至有定格——**你干成的事，游戏用镜头致意**
3. **碑刻与名录**：大工程立碑（书法影响品相）；《庄籍》记录每只牲畜、每级田、**每棵名木**的来历
4. **远望体系**：化神后被邻庄远望——千级梯田 + 羊群归圈 + 湖面反光的山庄，远看就是一幅画
5. **节庆**：满开梯田、首块陨铁出炉、名木开花、仙鹤落户，各有一次全庄异象，永久记入图志
