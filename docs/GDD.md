## 0. 一句话定位

**一个可以走进去、住下来、慢慢变强的私人山庄。**

不是打怪升级的闯关游戏，是一个"场"。评判标准只有一条：**像不像你想住的地方**。

### 三条体验支柱

| 支柱 | 含义 | 反面（要避免） |
|------|------|---------------|
| **归属感** | 这里的每块石头、每棵树是我选的、我摆的 | 地图是别人做的通用关卡 |
| **活着的** | 有风、有雨、有四季、有动物、水会动 | 静态模型展览馆 |
| **有根** | 打坐会强，但变强不是我来的理由 | 满屏数值、日常任务、排行榜 |

## 1. 六条反馈的根因诊断

| # | 现象 | 真实根因 | 归属里程碑 |
|---|------|---------|-----------|
| 1 | 往前走停不下来 | 输入系统缺陷：`keyup` 在窗口失焦/切标签页时丢失，键状态卡在"按下"。与网络无关 | M1 |
| 2 | 角色不像人、没五官、衣服臃肿 | **技术路线天花板**：手写几何体做不出人形。必须换成骨骼蒙皮模型 + 动作库 | M1 |
| 3 | 动作僵硬、跳跃像僵尸、没有跑 | 同上——手写代码只能做"摆臂"，做不出骨骼动画的关节链与动画混合 | M1 |
| 4 | 草又稀又大、树太矮 | 草坪不该用 3D 草叶做（成本高、必然稀疏）。正确做法是**地面贴图 + 密集短草片 + 色彩噪声**；树高应从 2.5m 提到 8~14m | M2 |
| 5 | 水潭进不去、没水花 | 现在把池塘当实心障碍。应改为**可涉水的浅水区**：水深判定 + 移动减速 + 水花粒子 + 涟漪 + 湿脚痕迹 | M3 |
| 6 | 没有动物、没生机 | 缺 fauna 系统。需要鱼群、鸟、鹤、鹿、猫、蝶虫，各带简单行为逻辑 | M2 |

**结论**：第 2、3 条是路线错误，不是参数问题。必须换角色资产管线，否则再怎么调都僵。

## 2. 世界设计

### 2.1 尺度

| 项 | 现在 | 目标 |
|----|------|------|
| 地图直径 | 260m | 340m |
| 可行走区域 | 中心广场 + 零散空地 | 七个功能分区，用山势/水系/林带自然分隔 |
| 树高 | 2.5m（视觉像灌木） | 松 9~14m、阔叶 7~11m、竹 6~9m |
| 视距 | 雾 60~230m | 雾 40~260m + 三层远山 |

### 2.2 七大分区

| 分区 | 位置 | 内容 | 情绪 |
|------|------|------|------|
| **山门区** | 南 | 石阶、牌楼、鼓石、灯笼 | 入门仪式感 |
| **前庭** | 中 | 主宅、影壁、石板路、老树 | 庄重 |
| **西苑·听雨** | 西 | 六角亭、竹林、听雨轩（打坐主点） | 静 |
| **东苑·荷风** | 东 | 池塘、曲桥、荷叶、芦苇、鱼 | 活 |
| **后山·观云** | 北 | 石阶上山、观云台、瀑布、松林 | 远 |
| **药圃** | 西南 | 菜畦、药草、瓜架（可种植/采集） | 家常 |
| **林界** | 外环 | 松林/竹林加密，形成视觉围墙 | 隔世 |

### 2.3 动线

山门 → 石板路 → 前庭 → （西：亭中打坐 ／ 东：池边喂鱼 ／ 北：登山望云）→ 药圃收菜

每个分区之间用**高差 + 植被 + 水面**隔断，不靠墙。走路时看不到全图，才有"探索"。

## 3. 角色系统（M1 核心）

### 3.1 技术方案：换骨骼模型

| 方案 | 评价 |
|------|------|
| ~~继续手写几何体~~ | ❌ 已证明做不到人形，放弃 |
| **Quaternius / Kenney CC0 人形（GLB，骨骼 + 130+ 动作）** | ✅ **推荐**。自带 idle / walk / run / jump / sit / 采集 等动作，五官与服饰为模型自身贴图，不用我画 |
| Ready Player Me 自定义形象 | 可选升级项，需要联网服务，后期考虑 |

技术栈：`GLTFLoader` + `AnimationMixer` + 动画状态机 + 动作混合（crossFade 0.15~0.25s）。

### 3.2 动作状态机

```
idle ──走──▶ walk ──持续加速──▶ run
  ▲           │                  │
  └──停───────┘◀──────减速───────┘
  │
  ├──空格──▶ jump(起跳) ─▶ air(滞空) ─▶ land(落地，0.2s 缓冲) ──▶ idle
  ├──E 近石台──▶ sit_meditate（循环）──▶ 起身 ──▶ idle
  └──入浅水──▶ wade（半身没水 + 减速 + 水花）
```

关键点（解决"僵硬"）：
- **起跳前有 0.08s 蓄力**、落地有 0.2s 屈膝缓冲 —— 这是"有重量"的来源
- 走/跑切换用交叉淡化，不是硬切
- 转向有角速度上限（不是瞬间转 180°）
- 加速跑：Shift 按住 → 速度 4.8 → 7.2 m/s，相机 FOV 从 52 拉到 57（速度感）

### 3.3 相机

- 默认第三人称：肩后 4.5~11m，带阻尼跟随（镜头滞后=有重量）
- 可切第一人称（走屋里看陈设、看山水）
- 涉水时相机自动抬高，避免入水

## 4. 自然系统

### 4.1 草坪（解决"又稀又大"）

三层叠加：
1. **地面贴图**：程序化噪声生成草地纹理（Canvas 生成，无需外网素材），近处草绿带斑驳
2. **短草片**：`InstancedMesh` 2 万株，高度 0.12~0.22m（现在 0.42m 太大），集中在广场周边与人常走区域
3. **草花点缀**：白/黄小花 300 株，成簇不长散

### 4.2 树（解决"太矮"）

| 树 | 目标高度 | 细节 |
|----|---------|------|
| 松 | 9~14m | 5~7 层错落冠 + 塔形轮廓 + 树皮纵纹 |
| 阔叶（樟/槐） | 7~11m | 主干分叉 3~4 支 + 6~9 团不规则冠 |
| 竹 | 6~9m | 竿粗 0.08m，竹叶分三簇垂坠 |
| 柳（池边） | 6~8m | 垂枝（顶点动画随风摆） |

### 4.3 动物（解决"没生机"）

| 动物 | 行为 | 数量 |
|------|------|------|
| 锦鲤 | 池中巡游、闻食聚集 | 12 尾 |
| 白鹭/鹤 | 池边站立、起飞掠过水面 | 2 只 |
| 麻雀 | 树枝跳跃、受惊成群飞走 | 8 只 |
| 鹿 | 林间缓行、抬头警戒 | 3 头 |
| 猫 | 亭下打盹、伸懒腰 | 1 只 |
| 蝶/蜻蜓 | 已知，加密到 10 只 | 10 只 |

行为逻辑：状态机（idle / move / flee / eat），无 AI 寻路，用路径点 + 距离触发。

### 4.4 水（解决"进不去"）

| 深度 | 表现 |
|------|------|
| 0~0.15m（池边浅滩） | 可直接走，脚步有水花 |
| 0.15~0.6m（池中） | 涉水模式：速度 ×0.45，水面到小腿，每步溅水花 + 涟漪扩散 |
| >0.6m（池心） | 禁止（防止走太深），提示"水太深了" |

水花：粒子系统（12 颗粒/步，向上抛物线，0.5s 消散）+ 水面涟漪 shader。

## 5. 修炼系统（克制，不喧宾夺主）

> 完整规则见 `docs/SYSTEMS.md` 第 2 章。此处只保留与"世界"相关的部分。

- 接回已有的 `skills.js`（15 种武功 × 10 层熟练度）与 `fate.js`（15 种命格）
- 开局抽命格（一次，可重抽 3 次）→ 决定起始资质偏向
- **五种修炼方式全部绑定场景**：打坐（石台）、站桩（瀑布下）、行功（走动时）、听雨（雨天亭中，唯一能升到"定"）、睡功（离线）
- 境界突破有镜头语言（天光变化 + 短促音效），不做大幅特效打断沉浸
- 离线收益：按时间差结算（关页面也涨，但每天上限，避免变成挂机游戏）

## 5.5 四体系总览

> 详见 `docs/SYSTEMS.md`。一句话版本：

| 体系 | 产出 | 核心机制 |
|------|------|---------|
| 修炼 | 元气 | 五种方式绑定场景；境界只解锁**权限**，不加战力 |
| 种田 | 地气 | 土壤三属性 + 八节气 + 轮作；作物**不会死** |
| 制作 | 精气 | 品质 = 熟练度 × **心境系数** × 材料；器物可**署名** |
| 交互 | 人气 | 三层：自处 / 相处（NPC 并行共处）/ 神交（异步：题壁·赠礼·借景·客访）|

贯穿四者的两条线：**心境**（越慢越高，决定转化效率与制作品质）与 **气象**（只增不减，决定山庄格局）。

## 6. 环境与氛围

| 系统 | 内容 |
|------|------|
| **昼夜** | 24 分钟一天（可调）；晨雾、正午强光、黄昏金光、夜晚月光+灯笼暖光 |
| **四季** | 春：樱/嫩绿；夏：荷/浓绿；秋：枫/金黄；冬：雪/枯枝。每 3 天轮换（可调） |
| **天气** | 晴 / 阴 / 小雨 / 大雨，随机切换；雨天水面涟漪加密、地面反光 |
| **风** | 全局风向，驱动竹、柳、草、旗幡摆动 |
| **声音** | 环境音（风/水/鸟/虫）+ 脚步（草地/石板/水三种材质）+ 古琴 BGM（可选静音） |

## 7. 技术架构

```
wuxia-rising/
├─ index.html
├─ lib/three.module.js + addons/(GLTFLoader, SkeletonUtils)
├─ assets/
│   ├─ models/character.glb   ← 骨骼人形 + 动作
│   └─ audios/*.mp3           ← 环境音（CC0）
└─ js/
   ├─ core/       engine.js(渲染/时钟) input.js(输入状态机) camera.js
   ├─ world/      terrain.js water.js sky.js weather.js
   ├─ build/      architecture.js props.js
   ├─ life/       flora.js fauna.js grass.js
   ├─ actor/      character.js animState.js
   ├─ system/     cultivation.js save.js
   └─ ui/         hud.js panel.js
```

**性能预算**：桌面 60fps / 移动 30fps；drawcall ≤ 150；单帧 CPU ≤ 8ms。
手段：InstancedMesh（草/石/花）、几何合批、LOD（远处树简化）、视锥剔除、阴影仅近景。

## 9. 待庄主拍板的三个决策

### 决策 1：角色美术路线

| 选项 | 说明 | 倾向 |
|------|------|------|
| **A. CC0 低多边形人形（Kenney/Quaternius）** | 五官清晰、骨骼动画全套、体积小（<2MB）、风格统一 | ✅ **推荐** |
| B. 卡通偏写实（KayKit Knight 系列） | 更精细但偏西式骑士风，需改造服饰 | 备选 |
| C. 继续手写几何体精修 | 已证明天花板低，不推荐 | ❌ |

### 决策 2：视角

- **第三人称肩后跟随**（推荐，看得到自己，符合"山庄漫游"）
- 可随时切第一人称（进屋、看景）

### 决策 3：起手优先级

- **先做 M1（人形 + 操控）**（推荐）——角色是每天盯着看的东西，不解决它，其他都是白搭
- 或先做 M2（自然与生机）——先把环境做美

## 10. 明确不做（防止范围失控）

- ❌ 战斗系统、PK、排行榜
- ❌ **实时联机**（不做同步在线；社交只走异步神交：题壁/赠礼/借景/客访）
- ❌ 抽卡/内购/日常任务/签到/体力
- ❌ 货币与商店（配方只从人、从探索来）
- ❌ 写实 PBR 材质（浏览器跑不动，也偏离水墨意境）
